# Run Growth Island (full loop)

```bash
cd ~/Desktop/growth-island
npm install
npm run dev
```

1. Open http://localhost:5173  
2. **Set sail** → pick a house  
3. Pause (☰) → **Sign in / Register**  
4. Walk · talk to coaches · play **The Feed** · **Puzzles**  
5. **Signal Tower** — write a hook → Score & capture (global board)  
6. Open a **second browser profile**, register another account, both online → see each other · **Connect**

API only: `npm run server` → http://localhost:8787/api/health
